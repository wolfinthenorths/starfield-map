# Источники готовых спрайтов и звуков

Новые изображения не генерировались. Спрайты используются без перерисовки; масштабирование пиксельное.

- `box-cut.png`, `boxOpening-cut.png`, `robotSprite-cut.png`, `floor-cut.png`, `terminal-cut.png`: готовые материалы карты Starfield из пользовательского набора Fallout / Fallout Tactics. Исходники и подготовка кадров перечислены в `../../../assets/SOURCES.md` основного репозитория. Анимация использует тот же десятикадровый атлас и неподвижную точку опоры, что и карта.
- `mysterium.webp`: оригинальное изображение «Мистериум.webp», предоставленное пользователем: https://drive.google.com/file/d/1cdlc-mOJh26C2B2DMtir0NhmP-b-zPEq/view. Файл используется без обработки и генерации; пропорции сохранены.
- `audio/click.mp3`, `confirm.mp3`, `denied.mp3`: готовые эффекты карты из **Kenney Interface Sounds**, CC0. https://kenney.nl/assets/interface-sounds
- `audio/box-open.mp3`, `box-close.mp3`, `robot.mp3`: готовые эффекты карты из **Kenney Sci-fi Sounds**, CC0. https://kenney.nl/assets/sci-fi-sounds

Права на графику Fallout принадлежат правообладателям оригинальных игр. Пользовательские материалы переиспользованы для того же фанатского проекта.
